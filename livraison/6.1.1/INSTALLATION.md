# Installation et retour arrière

1. Conserver une sauvegarde faite avec la version actuelle et vérifier sa copie externe.
2. Installer SmartMobilityTerrain-6.1.1.apk par-dessus la version compatible, sans désinstaller ni effacer les données Android.
3. Vérifier les comptes et la tournée, importer le nouveau modèle si vous disposez du GPS précédent.
4. Vérifier la carte, les deux modes d’identifiant et un export reçu dans Drive avant généralisation.

Même package et certificat que 6.1.0 / 5.1.4 ; aucun nouveau droit Android. Les livraisons précédentes restent conservées. Android peut refuser une version plus ancienne ; désinstaller efface les données privées. Les sauvegardes 6.1.1 à 49 champs ne sont pas compatibles avec les anciens APK. Préserver les sauvegardes anciennes et les données nouvelles avant toute procédure de retour.

Service Drive protocole 3 inchangé : même Code.gs, URL /exec, FOLDER_ID et clés. Pas de redéploiement requis pour un service déjà compatible.
